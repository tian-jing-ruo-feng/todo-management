# 组件规范

本文档定义了 Todo Management 项目的组件设计规范，确保组件的可复用性和可维护性。

## 组件设计原则

### 单一职责原则

每个组件应只负责单一功能，保持组件的简洁和专注。

```typescript
// ✅ 好的实践：单一职责
function TaskCard({ task }: { task: Task }) {
  return <div>{task.name}</div>
}

function TaskActions({ task }: { task: Task }) {
  return <button onClick={() => editTask(task)}>编辑</button>
}

// ❌ 不好的实践：职责过多
function TaskItem({ task }: { task: Task }) {
  const [editing, setEditing] = useState(false)
  const [loading, setLoading] = useState(false)

  // 包含渲染、编辑、删除等多个职责
  return <div>...</div>
}
```

### 组件组合

优先使用组件组合而非复杂的 props 传递。

```typescript
// ✅ 好的实践：使用 children 组合
function TaskForm({ children }: { children: React.ReactNode }) {
  return <Form layout="vertical">{children}</Form>
}

<TaskForm>
  <Form.Item name="name">
    <Input />
  </Form.Item>
</TaskForm>
```

### 可复用性

组件应设计为可复用，通过 props 接收配置。

```typescript
// ✅ 好的实践：可配置的组件
interface DateTimePickerProps {
  placeholder?: string
  onChange?: (value: string) => void
  value?: string
}

export default function DateTimePicker({
  placeholder = '选择时间',
  onChange,
  value,
}: DateTimePickerProps) {
  // ...
}
```

### 组件分层

按照功能复杂度对组件进行分层：

- **基础组件**（Base Components）：UI 原子组件，如 Button、Input
- **组合组件**（Composite Components）：由基础组件组合而成，如 TaskCard、KanbanColumn
- **容器组件**（Container Components）：处理业务逻辑，如 KanbanBoard
- **页面组件**（Page Components）：页面级别的布局和容器

## 状态管理

### useState 使用

#### 基本用法

```typescript
const [tasks, setTasks] = useState<Task[]>([])
const [loading, setLoading] = useState(false)
const [visible, setVisible] = useState(false)
```

#### 复杂对象状态

```typescript
interface FormState {
  name: string
  status: string
  priority: string
}

const [formData, setFormData] = useState<FormState>({
  name: '',
  status: '',
  priority: '',
})
```

#### 数组状态更新

```typescript
// 添加元素
setTasks((prev) => [...prev, newTask])

// 删除元素
setTasks((prev) => prev.filter((t) => t.id !== taskId))

// 更新元素
setTasks((prev) =>
  prev.map((t) => (t.id === taskId ? { ...t, name: newName } : t))
)
```

#### 对象状态更新

```typescript
setFormData((prev) => ({
  ...prev,
  name: newName,
}))
```

### useEffect 使用

#### 基本用法

```typescript
useEffect(() => {
  const loadStatusData = async () => {
    const statuses = await statusRepository.getAll()
    setStatusList(statuses)
  }

  loadStatusData()
}, [])
```

#### 依赖数组

确保依赖数组包含所有使用的变量。

```typescript
useEffect(() => {
  const grouped: Record<string, Task[]> = {}
  columns.forEach((col) => {
    grouped[col.id] = tasks.filter((t) => t.status === col.id)
  })
  setTasksByColumn(grouped)
}, [tasks, columns]) // 包含所有依赖
```

#### 清理函数

对于副作用，提供清理函数。

```typescript
useEffect(() => {
  const timer = setTimeout(() => {
    setTasksByColumn(grouped)
  }, 0)

  return () => clearTimeout(timer)
}, [tasks, columns])
```

### useCallback 使用

用于缓存函数，避免不必要的重创建。

```typescript
const handleEditTask = useCallback((task: Task) => {
  setEditingTask(task)
  setModalVisible(true)
}, []) // 空依赖数组，函数只创建一次

const handleTaskUpdate = useCallback(
  async (updatedTask: Task) => {
    await saveTask(updatedTask)
    setTasksByColumn((prev) => {
      // 更新逻辑
      return newTasksByColumn
    })
  },
  [getColumnByStatus] // 包含依赖
)
```

### useMemo 使用

用于缓存计算结果，避免重复计算。

```typescript
const sortedTasks = useMemo(() => {
  return tasks.sort((a, b) => {
    const sortA = a.sort ?? 0
    const sortB = b.sort ?? 0
    return sortB - sortA
  })
}, [tasks]) // 仅在 tasks 变化时重新计算

const filteredTasks = useMemo(() => {
  return tasks.filter((t) => !t.isRemoved)
}, [tasks])
```

### useRef 使用

#### 保存可变值

```typescript
const draggedTaskRef = useRef<Task | null>(null)

const handleDragStart = (event: DragStartEvent) => {
  const task = findTaskById(active.id)
  draggedTaskRef.current = task // 保存可变值
}
```

#### 访问 DOM 元素

```typescript
const inputRef = useRef<HTMLInputElement>(null)

const handleFocus = () => {
  inputRef.current?.focus()
}

<input ref={inputRef} />
```

### useContext 使用

对于全局状态，使用 Context。

```typescript
// 创建 Context
const TaskContext = createContext<TaskContextValue | null>(null)

// 提供 Context
export function TaskProvider({ children }: { children: React.ReactNode }) {
  const [tasks, setTasks] = useState<Task[]>([])

  return (
    <TaskContext.Provider value={{ tasks, setTasks }}>
      {children}
    </TaskContext.Provider>
  )
}

// 消费 Context
export function useTask() {
  const context = useContext(TaskContext)
  if (!context) {
    throw new Error('useTask must be used within TaskProvider')
  }
  return context
}
```

## 组件通信

### 父子组件通信

#### 父传子（Props）

```typescript
// 父组件
<KanbanColumn
  id="todo"
  title="待办"
  tasks={tasks}
  onEditTask={handleEditTask}
/>

// 子组件
interface KanbanColumnProps {
  id: string
  title: string
  tasks: Task[]
  onEditTask: (task: Task) => void
}

function KanbanColumn({ id, title, tasks, onEditTask }: KanbanColumnProps) {
  return (
    <div>
      <h2>{title}</h2>
      {tasks.map((task) => (
        <TaskCard
          key={task.id}
          task={task}
          onEdit={() => onEditTask(task)}
        />
      ))}
    </div>
  )
}
```

#### 子传父（回调函数）

```typescript
// 子组件触发事件
function TaskCard({ task, onEdit }: { task: Task; onEdit: () => void }) {
  return (
    <div>
      <h3>{task.name}</h3>
      <button onClick={onEdit}>编辑</button>
    </div>
  )
}

// 父组件处理事件
const handleEditTask = (task: Task) => {
  setEditingTask(task)
  setModalVisible(true)
}
```

### 兄弟组件通信

#### 通过父组件中转

```typescript
function Parent() {
  const [selectedTask, setSelectedTask] = useState<Task | null>(null)

  return (
    <>
      <TaskList
        tasks={tasks}
        onSelect={setSelectedTask}
      />
      <TaskDetail
        task={selectedTask}
      />
    </>
  )
}
```

#### 使用 Context

```typescript
const TaskContext = createContext<{
  selectedTask: Task | null
  setSelectedTask: (task: Task | null) => void
}>({
  selectedTask: null,
  setSelectedTask: () => {},
})

function Parent() {
  const [selectedTask, setSelectedTask] = useState<Task | null>(null)

  return (
    <TaskContext.Provider value={{ selectedTask, setSelectedTask }}>
      <TaskList />
      <TaskDetail />
    </TaskContext.Provider>
  )
}

function TaskList() {
  const { setSelectedTask } = useTask()
  return <button onClick={() => setSelectedTask(task)}>选择</button>
}

function TaskDetail() {
  const { selectedTask } = useTask()
  return <div>{selectedTask?.name}</div>
}
```

## 组件生命周期

### 函数式组件生命周期

函数式组件使用 useEffect 模拟生命周期。

```typescript
function Component() {
  // 挂载时执行
  useEffect(() => {
    console.log('组件挂载')
    loadInitialData()
  }, [])

  // 更新时执行（特定依赖）
  useEffect(() => {
    console.log('tasks 更新了')
    processData(tasks)
  }, [tasks])

  // 卸载时执行（返回清理函数）
  useEffect(() => {
    const timer = setInterval(() => {
      // 定时任务
    }, 1000)

    return () => {
      clearInterval(timer) // 清理
    }
  }, [])

  return <div>内容</div>
}
```

## 错误处理

### 错误边界

使用 React Error Boundary 捕获组件错误。

```typescript
class ErrorBoundary extends React.Component<
  { children: React.ReactNode },
  { hasError: boolean }
> {
  constructor(props: { children: React.ReactNode }) {
    super(props)
    this.state = { hasError: false }
  }

  static getDerivedStateFromError() {
    return { hasError: true }
  }

  render() {
    if (this.state.hasError) {
      return <div>出错了</div>
    }
    return this.props.children
  }
}

<ErrorBoundary>
  <App />
</ErrorBoundary>
```

## 性能优化

### React.memo

使用 React.memo 避免不必要的重渲染。

```typescript
const TaskCard = React.memo(function TaskCard({ task }: { task: Task }) {
  return <div>{task.name}</div>
})
```

### useMemo

缓存计算结果。

```typescript
const expensiveValue = useMemo(() => {
  return heavyComputation(tasks)
}, [tasks])
```

### useCallback

缓存回调函数。

```typescript
const handleClick = useCallback(() => {
  doSomething()
}, [dependency])
```

### 虚拟化长列表

对于大量数据的列表，使用虚拟滚动。

```typescript
import { useVirtualizer } from '@tanstack/react-virtual'

function VirtualList({ items }: { items: Task[] }) {
  const parentRef = useRef<HTMLDivElement>(null)

  const virtualizer = useVirtualizer({
    count: items.length,
    getScrollElement: () => parentRef.current,
    estimateSize: () => 100,
  })

  return (
    <div ref={parentRef} style={{ height: '600px', overflow: 'auto' }}>
      <div
        style={{
          height: `${virtualizer.getTotalSize()}px`,
          width: '100%',
          position: 'relative',
        }}
      >
        {virtualizer.getVirtualItems().map((virtualItem) => (
          <div
            key={virtualItem.key}
            style={{
              position: 'absolute',
              top: 0,
              left: 0,
              width: '100%',
              transform: `translateY(${virtualItem.start}px)`,
            }}
          >
            {items[virtualItem.index].name}
          </div>
        ))}
      </div>
    </div>
  )
}
```

## 总结

遵循以上组件规范，可以确保组件：

- **可复用性**：组件设计灵活，易于在不同场景使用
- **可维护性**：代码结构清晰，易于理解和修改
- **性能优化**：避免不必要的渲染和计算
- **类型安全**：充分利用 TypeScript 类型系统
- **一致性**：团队组件风格统一
